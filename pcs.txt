1. HIGH-LEVEL INTUITION & REAL-WORLD MOTIVATION
================================================================================

In machine learning and statistics, high-dimensional datasets introduce severe 
practical challenges collectively known as the "Curse of Dimensionality":

1. Data Sparsity: As dimensionality grows, the volume of feature space grows 
   exponentially, making the available data points sparse and distance metrics 
   (like Euclidean distance) less informative.
2. Multicollinearity: Features often measure overlapping information (e.g., house 
   square footage, room count, exterior footprint). This introduces redundant weights 
   and high variance in linear models.
3. Computational Overhead: Matrix operations scale polynomially/exponentially with 
   feature count p.
4. Human Cognition Limits: Visual exploration is strictly bounded to 2D/3D plots.

PCA (Principal Component Analysis) is an UNSUPERVISED linear transformation 
technique that projects data from a p-dimensional space into a k-dimensional 
subspace (where k <= p) along directions of MAXIMUM VARIANCE.

Core Principle:
Variance = Information. 
If data does not vary along a particular axis (variance ≈ 0), that axis provides 
no discriminatory power for machine learning models and can be safely dropped.

2. CORE CONCEPTUAL DIFFERENCES
================================================================================

A. FEATURE SELECTION vs DIMENSIONALITY REDUCTION (FEATURE EXTRACTION)
---------------------------------------------------------------------
* Feature Selection:
  - Chooses a subset of the original variables and discards the rest.
  - Example: Given [Height, Weight, Age, Shoe Size], choose [Height, Age].
  - Pro: Retains original interpretability.
  - Con: Throws away all unique variance present in dropped features.

* Dimensionality Reduction via PCA (Feature Extraction):
  - Creates completely NEW composite variables (Principal Components) as linear 
    combinations of ALL original features.
  - Example: PC1 = 0.65*(Height) + 0.72*(Weight) + 0.24*(Shoe Size).
  - Pro: Preserves the maximum possible joint variance while reducing dimensions.
  - Con: Loses raw feature interpretability (PC1 is a blended abstract metric).

B. COVARIANCE vs CORRELATION
----------------------------
* Covariance (Cov(X, Y)):
  - Measures the directional linear joint variability between two features.
  - Unstandardized: Depends entirely on the measurement scale (e.g., meters vs mm).
  - Formula: Cov(X, Y) = (1 / (n - 1)) * sum((X_i - mean_X) * (Y_i - mean_Y))

* Correlation (Corr(X, Y) or Pearson's r):
  - Scaled covariance between -1.0 and +1.0.
  - Dimensionless: Scale-invariant.
  - Formula: Corr(X, Y) = Cov(X, Y) / (std_X * std_Y)

* Rule of Thumb in PCA:
  - If features have the SAME units/scale: Perform PCA on Covariance Matrix.
  - If features have DIFFERENT units (e.g., Age in years, Income in $): MUST standardize 
    first (Z-score), which is mathematically identical to performing PCA on the 
    Correlation Matrix.

3. MATHEMATICAL FOUNDATIONS
================================================================================

1. Standardization (Z-score normalization):
   For each sample x_i in feature j:
   
          z_ij = (x_ij - mu_j) / sigma_j
          
   where mu_j is the mean and sigma_j is the standard deviation.

2. Zero-Centered Data Matrix X (n samples x p features):
   
          X = [ (x_1 - mu)^T ]
              [ (x_2 - mu)^T ]
              [      ...     ]
              [ (x_n - mu)^T ]

3. Covariance Matrix Sigma (p x p):
   
          Sigma = (1 / (n - 1)) * (X^T @ X)

   Structure of Sigma:
   [ Var(X1)       Cov(X1, X2)   ...  Cov(X1, Xp) ]
   [ Cov(X2, X1)   Var(X2)       ...  Cov(X2, Xp) ]
   [ ...           ...           ...  ...         ]
   [ Cov(Xp, X1)   Cov(Xp, X2)   ...  Var(Xp)     ]

4. Eigendecomposition:
   We seek orthogonal vectors v and scalars lambda such that:
   
          Sigma @ v = lambda * v

   - v (Eigenvector): The directional vector of the principal component.
   - lambda (Eigenvalue): The amount of variance captured along direction v.

   Characteristic Equation to solve for eigenvalues:
   
          det(Sigma - lambda * I) = 0

5. Projection to Subspace (Dimensionality Reduction):
   Sort eigenvalues descending: lambda_1 >= lambda_2 >= ... >= lambda_p.
   Select top k eigenvectors to form projection matrix W (p x k):
   
          W = [ v_1,  v_2,  ... ,  v_k ]

   Project original centered data X (n x p) into reduced space Y (n x k):
   
          Y = X @ W

6. Explained Variance Ratio:
   
          Explained Variance Ratio (PC_i) = lambda_i / sum(lambda_all)

       - The orthogonal projection preserves the maximum possible variance of points.

           |

           |                                Eigenvectors: v_1, v_2 ...
           v
  [ Select Top-k Eigenvectors ] ----------> Transformation Matrix W (p x k)
           |
           v
  [ Matrix Multiplication ] --------------> Reduced Transformed Data Y = X @ W (n x k)

5. COMPREHENSIVE END-TO-END HAND CALCULATION WALKTHROUGH
================================================================================

Let us work through a complete, verifiable 2D dataset with n = 5 students:
Features: X1 = Math Exam Score, X2 = Physics Exam Score

RAW DATA TABLE:
---------------
  Student | Math (X1) | Physics (X2)
  --------+-----------+-------------
     1    |     4     |      5
     2    |     8     |     10
     3    |    13     |     11
     4    |     7     |      8
     5    |    13     |     16

--------------------------------------------------------------------------------
STEP 1: MEAN CENTERING
--------------------------------------------------------------------------------
Calculate Feature Means:
  mu_1 = (4 + 8 + 13 + 7 + 13) / 5 = 45 / 5 = 9.0
  mu_2 = (5 + 10 + 11 + 8 + 16) / 5 = 50 / 5 = 10.0

Subtract Mean from each data point:
  Student 1: [ 4 - 9,   5 - 10 ] = [ -5, -5 ]
  Student 2: [ 8 - 9,  10 - 10 ] = [ -1,  0 ]
  Student 3: [13 - 9,  11 - 10 ] = [  4,  1 ]
  Student 4: [ 7 - 9,   8 - 10 ] = [ -2, -2 ]
  Student 5: [13 - 9,  16 - 10 ] = [  4,  6 ]

Centered Matrix X (5 x 2):
      [ -5  -5 ]
      [ -1   0 ]
  X = [  4   1 ]
      [ -2  -2 ]
      [  4   6 ]

--------------------------------------------------------------------------------
STEP 2: COMPUTE COVARIANCE MATRIX (Sigma)
--------------------------------------------------------------------------------
Formula: Sigma = (1 / (n - 1)) * (X^T @ X), with n - 1 = 4.

1. Variance of X1:
   Var(X1) = ((-5)^2 + (-1)^2 + 4^2 + (-2)^2 + 4^2) / 4
           = (25 + 1 + 16 + 4 + 16) / 4
           = 62 / 4 = 15.5

2. Variance of X2:
   Var(X2) = ((-5)^2 + 0^2 + 1^2 + (-2)^2 + 6^2) / 4
           = (25 + 0 + 1 + 4 + 36) / 4
           = 66 / 4 = 16.5

3. Covariance between X1 and X2:
   Cov(X1, X2) = ((-5)*(-5) + (-1)*(0) + (4)*(1) + (-2)*(-2) + (4)*(6)) / 4
               = (25 + 0 + 4 + 4 + 24) / 4
               = 57 / 4 = 14.25

Covariance Matrix Sigma:
            [ 15.50   14.25 ]
  Sigma =   [ 14.25   16.50 ]

--------------------------------------------------------------------------------
STEP 3: COMPUTE EIGENVALUES
--------------------------------------------------------------------------------
Solve: det(Sigma - lambda * I) = 0

  det | 15.5 - lambda      14.25       | = 0
      |    14.25        16.5 - lambda  |

  (15.5 - lambda) * (16.5 - lambda) - (14.25)^2 = 0
  lambda^2 - (15.5 + 16.5)*lambda + (15.5 * 16.5) - 203.0625 = 0
  lambda^2 - 32.0*lambda + 255.75 - 203.0625 = 0
  lambda^2 - 32.0*lambda + 52.6875 = 0

Applying Quadratic Formula:
  lambda = [ 32.0 +- sqrt((-32.0)^2 - 4 * 1 * 52.6875) ] / 2
  lambda = [ 32.0 +- sqrt(1024.0 - 210.75) ] / 2
  lambda = [ 32.0 +- sqrt(813.25) ] / 2
  lambda = [ 32.0 +- 28.5175 ] / 2

Eigenvalues:
  lambda_1 = (32.0 + 28.5175) / 2 = 30.25875 ≈ 30.26
  lambda_2 = (32.0 - 28.5175) / 2 =  1.74125 ≈  1.74

Variance Explained:
  Total Variance = lambda_1 + lambda_2 = 30.26 + 1.74 = 32.0
  PC1 Explained Ratio = 30.26 / 32.0 = 0.9456 (94.56%)
  PC2 Explained Ratio =  1.74 / 32.0 = 0.0544 ( 5.44%)

--------------------------------------------------------------------------------
STEP 4: COMPUTE EIGENVECTORS
--------------------------------------------------------------------------------
For lambda_1 = 30.25875:
  (Sigma - lambda_1 * I) @ v1 = 0

  [ 15.5 - 30.25875      14.25     ] [ v_11 ]   [ 0 ]
  [      14.25      16.5 - 30.25875] [ v_12 ] = [ 0 ]

  [ -14.75875    14.25    ] [ v_11 ]   [ 0 ]
  [   14.25    -13.75875  ] [ v_12 ] = [ 0 ]

From row 1:
  -14.75875 * v_11 + 14.25 * v_12 = 0
  v_12 = (14.75875 / 14.25) * v_11 = 1.0357 * v_11

Normalize to unit length (||v1|| = 1):
  v_11^2 + v_12^2 = 1
  v_11^2 + (1.0357 * v_11)^2 = 1
  v_11^2 * (1 + 1.0727) = 1
  v_11^2 = 1 / 2.0727 = 0.48246
  v_11 = sqrt(0.48246) ≈ 0.6946
  v_12 = 1.0357 * 0.6946 ≈ 0.7194

Eigenvector for PC1:
  v1 = [ 0.6946 ]
       [ 0.7194 ]

(Similarly, orthogonal eigenvector v2 for PC2 is [ -0.7194, 0.6946 ]^T)

--------------------------------------------------------------------------------
STEP 5: PROJECT DATA ONTO PC1 (2D -> 1D REDUCTION)
--------------------------------------------------------------------------------
Projection Matrix W = [ v1 ] (2 x 1)
Y = X @ W

Sample 1: (-5)*(0.6946) + (-5)*(0.7194) = -3.4730 - 3.5970 = -7.07
Sample 2: (-1)*(0.6946) +  (0)*(0.7194) = -0.6946 + 0.0000 = -0.69
Sample 3:  (4)*(0.6946) +  (1)*(0.7194) =  2.7784 + 0.7194 = +3.50
Sample 4: (-2)*(0.6946) + (-2)*(0.7194) = -1.3892 - 1.4388 = -2.83
Sample 5:  (4)*(0.6946) +  (6)*(0.7194) =  2.7784 + 4.3164 = +7.09

Transformed 1D Representation:
  Student 1 -> PC1 = -7.07
  Student 2 -> PC1 = -0.69
  Student 3 -> PC1 = +3.50
  Student 4 -> PC1 = -2.83
  Student 5 -> PC1 = +7.09

Result: 1 feature replaces 2 features, while preserving 94.56% of total variance!

6. MODERN PRODUCTION IMPLEMENTATION: SVD vs EIGENDECOMPOSITION
================================================================================

Why does Scikit-Learn NOT compute the covariance matrix directly?
1. Computational Complexity: Forming X^T @ X takes O(n * p^2).
2. Numerical Precision Loss: Squaring matrix condition numbers causes precision loss.

Instead, production engines use Singular Value Decomposition (SVD) on X directly:

          X = U @ S @ V^T

Where:
  - X: Centered data matrix (n x p)
  - U: Left singular vectors (n x n, orthogonal)
  - S: Singular values diagonal matrix (n x p, values s_1, s_2, ...)
  - V^T: Right singular vectors (p x p, orthogonal). The rows of V^T are the EXACT 
         eigenvectors of X^T @ X!

Mathematical Bridge between SVD and Eigendecomposition:
  Sigma = (1 / (n - 1)) * (X^T @ X)
        = (1 / (n - 1)) * (V @ S^T @ U^T) @ (U @ S @ V^T)
        = (1 / (n - 1)) * V @ S^2 @ V^T

  Therefore:
  - Eigenvectors = Columns of V (rows of V^T)
  - Eigenvalues lambda_i = (s_i^2) / (n - 1)
  - Projected Data Y = X @ V = U @ S

7. DIAGNOSTICS & SELECTING THE NUMBER OF COMPONENTS (k)
================================================================================

1. Scree Plot (Elbow Method):
   Plot eigenvalue / explained variance vs Component Index.
   Look for the "elbow" point where the marginal variance drop levels off.

   Variance
      ^
   30 | * (PC1: 94.6%)
      |
      |
    5 |
      |
    1 |        * (PC2: 5.4%)
      +-------------------------> Component Number
               1        2

2. Cumulative Explained Variance Threshold:
   Select smallest k such that:
   sum_{i=1}^k (lambda_i) / sum(lambda_all) >= Threshold (commonly 90% or 95%).

3. Kaiser Criterion (for Standardized Data):
   Retain components whose eigenvalue lambda_i > 1.0 (meaning the component captures 
   more variance than an individual standardized original feature).

8. PRODUCTION PYTHON CODE (FROM SCRATCH vs SCIKIT-LEARN)
================================================================================

Save and run this script in VS Code:

```python
import numpy as np
from sklearn.decomposition import PCA
from sklearn.preprocessing import StandardScaler

# 1. Dataset from walkthrough
X_raw = np.array([
    [4, 5],
    [8, 10],
    [13, 11],
    [7, 8],
    [13, 16]
], dtype=float)

# ==========================================
# A. NUMPY FROM SCRATCH (Eigendecomposition)
# ==========================================
# Step 1: Mean centering
X_mean = np.mean(X_raw, axis=0)
X_centered = X_raw - X_mean

# Step 2: Covariance matrix (ddof=1 for sample covariance n-1)
cov_matrix = np.cov(X_centered, rowvar=False)

# Step 3: Eigendecomposition
eigenvalues, eigenvectors = np.linalg.eigh(cov_matrix)

# Sort descending
idx = np.argsort(eigenvalues)[::-1]
eigenvalues = eigenvalues[idx]
eigenvectors = eigenvectors[:, idx]

# Step 4: Projection to 1D (top 1 eigenvector)
W = eigenvectors[:, :1]
Y_scratch = X_centered @ W

print("--- NUMPY FROM SCRATCH ---")
print("Eigenvalues:", eigenvalues)
print("PC1 Eigenvector:\n", eigenvectors[:, 0])
print("1D Projections:\n", Y_scratch)

# ==========================================
# B. SCIKIT-LEARN COMPARISON
# ==========================================
pca = PCA(n_components=1)
Y_sklearn = pca.fit_transform(X_raw)

print("\n--- SCIKIT-LEARN ---")
print("Explained Variance:", pca.explained_variance_)
print("Explained Variance Ratio:", pca.explained_variance_ratio_)
print("PC1 Vector:\n", pca.components_[0])
print("1D Projections:\n", Y_sklearn)
```

9. SUMMARY CHEAT SHEET & COMMON PITFALLS
================================================================================

[+] DOs:
  - ALWAYS center data (mean = 0) before performing PCA.
  - Standardize (scale to unit variance) if features have different measurement units.
  - Use SVD under the hood for computational efficiency and numerical stability.
  - Check cumulative explained variance to determine the optimal number of components.

[-] DONTs / PITFALLS:
  - Do NOT fit PCA on the Test set! Fit PCA ONLY on the Training set, then transform Test.
  - Do NOT use standard PCA for non-linear relationships (use Kernel PCA or t-SNE / UMAP).
  - Do NOT assume PCA will automatically improve classification accuracy; it maximizes 
    variance, which is unsupervised and may not align with class labels.
  - Do NOT use PCA if interpretability of raw individual features is strictly mandatory.
