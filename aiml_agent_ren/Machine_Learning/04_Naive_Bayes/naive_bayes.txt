--------------------------------------------------------------------------------
1. THE FOUNDATION: BAYES' THEOREM
--------------------------------------------------------------------------------

Bayes' Theorem calculates the probability of an outcome (class y) given some 
observed evidence or features (X).

Mathematical Formula:
---------------------
               P(X | y) * P(y)
  P(y | X) = -----------------
                   P(X)

Term-by-Term Breakdown:
-----------------------
* P(y | X)  [Posterior Probability]:
  - What it means: The probability that the class is 'y', given that we have 
    observed features 'X'.
  - Simple words: "What we want to predict." (e.g., Is this email Spam given its words?)

* P(y)      [Prior Probability]:
  - What it means: The default base probability of class 'y' occurring in our 
    training dataset before looking at any features.
  - Simple words: "How common is this class normally?" 
    Formula: Total Spam emails / Total emails in dataset.

* P(X | y)  [Likelihood]:
  - What it means: The probability of seeing the features 'X' when we already know 
    the class is 'y'.
  - Simple words: "If an email is known to be Spam, how likely does it contain these words?"

* P(X)      [Evidence / Marginal Probability]:
  - What it means: The total probability of observing the feature vector 'X' across 
    all possible classes.
  - Simple words: "How common are these features in general across everything?"


--------------------------------------------------------------------------------
2. THE "NAIVE" ASSUMPTION IN MACHINE LEARNING
--------------------------------------------------------------------------------

In real-world Machine Learning, the input X is not a single value; it is a vector 
of multiple features:
  X = (x_1, x_2, x_3, ..., x_n)

The Problem:
------------
Calculating the joint likelihood P(x_1, x_2, ..., x_n | y) directly is nearly 
impossible because you would need to see every single combination of words/features 
together multiple times in your dataset.

The "Naive" Solution (Conditional Independence):
------------------------------------------------
Naive Bayes assumes that EVERY feature x_i is completely independent of every other 
feature x_j, given the class y.

This simplifies the joint likelihood into a simple product of individual probabilities:
  P(x_1, x_2, ..., x_n | y) = P(x_1 | y) * P(x_2 | y) * ... * P(x_n | y)
                            = Π P(x_i | y)   (for i = 1 to n)

The Decision Rule (MAP - Maximum A Posteriori):
-----------------------------------------------
To predict the winning class (y_hat), we find the class 'y' that maximizes this product:

  y_hat = argmax_y [ P(y) * Π P(x_i | y) ]

Note: We safely drop the denominator P(X) because it is identical for all classes 
and does not change which class score is the highest.


--------------------------------------------------------------------------------
3. COMMON NAIVE BAYES VARIANTS
--------------------------------------------------------------------------------

How we calculate P(x_i | y) depends on what kind of feature data we have:

1. GAUSSIAN NAIVE BAYES
   - Data Type : Continuous / Real numbers (e.g., height, temperature, sensor values).
   - Assumption: Features follow a Normal (Bell Curve) distribution.
   - Formula   :
                             1               /  -(x_i - μ_y)^2  \
       P(x_i | y) = -------------------- exp| ----------------- |
                     sqrt(2 * π * σ_y^2)     \    2 * σ_y^2    /
     where μ_y is the mean and σ_y^2 is the variance of feature x_i for class y.
   - Use Cases : Sensor data, Iris flower classification, medical measurements.

2. MULTINOMIAL NAIVE BAYES
   - Data Type : Discrete counts / Frequencies (e.g., word count = 3, word count = 5).
   - Formula   :
                      N_yi + α
       P(x_i | y) = ------------
                     N_y + α * |V|
     where N_yi is count of word i in class y, N_y is total word count in class y, 
     and |V| is total vocabulary size.
   - Use Cases : Text classification, spam filtering, TF-IDF / Bag of Words models.

3. BERNOULLI NAIVE BAYES
   - Data Type : Binary / Boolean (0 or 1, True or False).
   - Formula   :
       P(x_i | y) = (p_yi)^(x_i) * (1 - p_yi)^(1 - x_i)
     where p_yi is the probability that feature i occurs in class y.
   - Use Cases : Document categorization based on word presence/absence (Did "free" appear? Yes/No).


--------------------------------------------------------------------------------
4. ADVANCED CONCEPTS & PRACTICAL HANDLING
--------------------------------------------------------------------------------

1. Laplace / Lidstone Smoothing (Zero-Frequency Problem):
   - Problem: If a word never appears with a class during training, P(x_new | y) = 0.
     Multiplying by 0 wipes out the ENTIRE probability product.
   - Solution: Add a pseudo-count 'α' (typically α = 1):
                      Count(x_i, y) + α
       P(x_i | y) = -----------------------
                     Σ Count(x, y) + α * |V|
     where |V| is the total vocabulary size.

2. Log-Space Computation (Preventing Arithmetic Underflow):
   - Problem: Multiplying dozens or hundreds of tiny decimals (0.001 * 0.0004 * ...) 
     causes floating-point underflow (computer rounds it to 0.0).
   - Solution: Use natural logarithms (ln). This converts multiplication into addition:
       y_hat = argmax_y [ ln P(y) + Σ ln P(x_i | y) ]

3. Semi-Supervised Naive Bayes (EM Algorithm):
   - Used when labeled data is scarce but unlabeled data is plentiful.
   - E-step (Expectation): Estimate soft probabilities for unlabeled data using the current model.
   - M-step (Maximization): Re-train the model (priors & likelihoods) using both labeled 
     and soft-labeled data. Repeat until convergence.

4. Correlated Feature Penalty:
   - If features are strongly correlated (e.g., "cheap" and "discount" appearing together), 
     Naive Bayes double-counts evidence.
   - Result: Model probabilities get pushed extremely close to 0 or 1 (overconfident), 
     though final ranking/classification decisions usually remain solid.

           DETAILED BREAKDOWN OF NAIVE BAYES VARIANTS (STUDY NOTES)

--------------------------------------------------------------------------------
1. GAUSSIAN NAIVE BAYES (For Continuous / Real Numbers)
--------------------------------------------------------------------------------

WHEN TO USE:
Use Gaussian Naive Bayes when features are real numbers that can take any value 
on a continuous scale (like height, temperature, blood pressure, or sensor readings).
It assumes that values for each class follow a classic bell-shaped curve 
(Normal / Gaussian distribution).

THE FORMULA:
--------------------------------------------------------------------------------
                         1               /  -(x_i - μ_y)^2  \
   P(x_i | y) = -------------------- exp| ----------------- |
                 sqrt(2 * π * σ_y^2)     \    2 * σ_y^2    /
--------------------------------------------------------------------------------

TERM-BY-TERM EXPLANATION:
* x_i:
  - The specific feature value you want to test.
  - Example: A patient's height = 175 cm.

* μ_y (Mean / Average):
  - The average value of that feature for class y in the training data.
  - Example: Average height of males = 178 cm.

* σ_y^2 (Variance):
  - How spread out the numbers are around the average for class y.

* sqrt(2 * π * σ_y^2) [Normalization Constant]:
  - Ensures the total area under the bell curve equals 1 (a valid probability).

* exp( -(x_i - μ_y)^2 / (2 * σ_y^2) ) [Distance Penalty]:
  - Measures the squared distance (x_i - μ_y)^2 between test value and average.
  - If x_i is very close to the average μ_y, the penalty is small -> HIGH probability.
  - If x_i is far from the average, the probability drops exponentially toward 0.

SIMPLE REAL-WORLD EXAMPLE:
Classifying whether a patient is healthy or has a fever based on body temperature 
(38.5°C). The model compares 38.5°C to the bell curves of healthy vs. sick patients 
to see which curve fits better.


--------------------------------------------------------------------------------
2. MULTINOMIAL NAIVE BAYES (For Word Counts / Frequencies)
--------------------------------------------------------------------------------

WHEN TO USE:
Use Multinomial Naive Bayes when features represent discrete counts or frequencies—
most commonly how many times specific words appear in a document.

THE FORMULA:
--------------------------------------------------------------------------------
                  N_yi + α
   P(x_i | y) = ------------
                 N_y + α * |V|
--------------------------------------------------------------------------------

TERM-BY-TERM EXPLANATION:
* N_yi:
  - How many times word/feature x_i appeared in all training examples of class y.
  - Example: The word "free" appeared 50 times in Spam emails.

* N_y:
  - The total count of all words combined across class y.
  - Example: 10,000 total words across all Spam emails.

* α (Smoothing Parameter, usually 1):
  - A dummy count added so a word never seen in training doesn't give 0 probability.

* |V| (Vocabulary Size):
  - Total number of unique words across the entire dataset.
  - Multiplying α by |V| in the bottom ensures all probabilities still sum to 1.

SIMPLE REAL-WORLD EXAMPLE:
Spam vs. Not-Spam filtering: If an email repeats "cash" 3 times and "win" 2 times, 
Multinomial Naive Bayes uses the frequency of each word relative to total word counts 
to decide the label.


--------------------------------------------------------------------------------
3. BERNOULLI NAIVE BAYES (For Binary Yes/No Features)
--------------------------------------------------------------------------------

WHEN TO USE:
Use Bernoulli Naive Bayes when you only care whether a feature is present (1) 
or absent (0), completely ignoring how many times it appeared.

THE FORMULA:
--------------------------------------------------------------------------------
   P(x_i | y) = (p_yi)^(x_i) * (1 - p_yi)^(1 - x_i)
--------------------------------------------------------------------------------

TERM-BY-TERM EXPLANATION:
* x_i:
  - Binary feature value (1 if present, 0 if absent).

* p_yi:
  - The probability that class y contains feature x_i.
  - Example: 80% (0.80) of Spam emails contain the word "offer".

* (p_yi)^(x_i) [Active when x_i = 1]:
  - If word is present (x_i = 1): (p_yi)^1 = p_yi, and (1 - p_yi)^0 = 1.
  - Result: It simply becomes p_yi.

* (1 - p_yi)^(1 - x_i) [Active when x_i = 0]:
  - If word is absent (x_i = 0): (p_yi)^0 = 1, and (1 - p_yi)^1 = (1 - p_yi).
  - Result: Actively penalizes the class if a typical word is missing.

SIMPLE REAL-WORLD EXAMPLE:
Short-text sentiment analysis (like a tweet): You check if the word "terrible" 
exists (1) or not (0). Even if typed 3 times, Bernoulli treats it purely as 1.
